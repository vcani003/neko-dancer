Playback smoke test

The one place the real YouTube is allowed. Everything else in the playback layer runs on fakes — no automated test may require YouTube — so this page exists to check the assumptions those fakes are built on. Run it once per change to the playback layer, and paste the result into the phase notes.

Open it by hostname (http://something.local:5180/smoke.html), never by IP: YouTube refuses restriction-bearing videos on a numeric origin.
