## LDUR naming / branding

**Required now:** rename the ranking UI from Leaderboard to
**LDUR Board** when that screen exists.

LDUR is **Left, Down, Up, Right** — the four directions. It is
in-universe vocabulary, not a punchline we explain. Always
**LDUR**, never Ldur or ldur.

| Where | Copy |
|---|---|
| Main ranking page | `LDUR Board` |
| Tagline / loading / flavour (optional) | `Follow the LDUR.` |

`Follow the LDUR` is selective. Use it where flavour text already
belongs. Do not sprinkle LDUR wordplay so the joke has to be
explained.

There is no public ranking page yet (`ROOM-LOOPS.md` — out of
scope). This item is the name that page gets, and the tagline we
may put on a loading line later. Do not add a board just to hang
the joke on.
